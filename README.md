# Fichiers d'installation Arch Linux

Fichiers longs des guides « Arch Linux : LUKS + btrfs + systemd-boot » et
« Arch Linux : optimisations post-installation », à télécharger avec curl
au lieu de les retaper. Toujours relire un fichier avant de l'installer.

| Fichier | Guide | Commande |
|---|---|---|
| `arch/snapper` | guide 1, section 14 | `sudo curl -fsSLo /usr/local/bin/snapper https://yifu.github.io/arch/snapper` |
| `arch/zshrc` | guide 2, section 3.3 | `curl -fsSLo ~/.zshrc https://yifu.github.io/arch/zshrc` |

Dépôt public : ne jamais y mettre de clé, de mot de passe ni d'information interne.
